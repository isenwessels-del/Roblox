# Open the game in Roblox Studio

`StealAHouse.rbxlx` is the complete launch place, with every game script embedded. Open it using **File → Open from File**, then press **Play**. The map is generated when the server starts.

`StealAHouse-launch.zip` includes the same place, the Rojo source, documentation and a self-contained offline Windows transfer script. Extract it before opening the place.

The place's SHA-256 is `4cc6baf273d62ef9346b50abf43a4fd1c9e807bcbf8446ab84dbace97ac41775`. The ZIP contains its own per-file SHA-256 manifest.

These files are the launch snapshot. Source edits require a new build. See the main project README for setup and persistence configuration, and `docs/VALIDATION.md` for the required Studio multiplayer checks.

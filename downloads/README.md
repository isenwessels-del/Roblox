# Open the game in Roblox Studio

`StealAHouse.rbxlx` is the neighborhood house-theft place, with all 23 game scripts embedded. Open it using **File → Open from File**, then press **Play**. The town is generated when the server starts.

`StealAHouse-launch.zip` includes the same place, the Rojo source, documentation and a self-contained offline Windows transfer script. Extract it before opening the place.

The place's SHA-256 is `0993ece32de703422366563196a332396b0964fb0f40255c02cf474eccda2819`. The ZIP contains its own per-file SHA-256 manifest.

These files are the neighborhood snapshot. Source edits require a new build. Set maximum players to seven and avatar type to R15. Studio progress is temporary by default. See the main project README for persistence configuration and `docs/VALIDATION.md` for required Studio multiplayer checks. Sound IDs are optional and empty by default.

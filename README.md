# Steal a House — neighborhood theft game

Steal growing prefab houses, carry them home, build a collection, and collect rent. Train your running speed, expand your base, and defend houses from other players. This version follows the publicly described **Steal An Egg** steal → grow/build → income → treadmill/base progression loop, with original house models, names and interface.

The official Roblox listing confirmed stealing, hatching, income, speed training, base upgrades, sizes and mutations. The provided video was inaccessible and the share link required authentication. Exact original visuals, timings, prices and rules were not verified. [Reference research](docs/REFERENCE.md) separates those facts from this game's choices. The previous furniture-robbery game remains on `codex/steal-a-house-launch`; its older specification is preserved in `docs/archive/`.

## Download and play on Windows

1. Open the [neighborhood branch on GitHub](https://github.com/isenwessels-del/Roblox/tree/codex/steal-a-house-neighborhood).
2. Select **Code → Download ZIP**, then right-click the downloaded ZIP and select **Extract All**.
3. In Roblox Studio, select **File → Open from File** and open `downloads/StealAHouse.rbxlx` inside the extracted project.
4. Press **Play**. The map is generated by the server when Play starts; an empty editing view is expected.

You can instead download `downloads/StealAHouse-launch.zip` from the GitHub file page using **Download raw**. Extract it and open `StealAHouse/StealAHouse.rbxlx`. This ZIP includes the source, documentation, per-file checksums, and a self-contained offline PowerShell transfer script; that script needs no variables from an earlier window. Checked-in downloads represent this branch's release snapshot. Rebuild after changing source.

## Playable loop

You receive one of **seven bases**, **$500**, a finished Starter Cottage and ten house pads. The cottage generates $2/s. Walk onto a green rent pad or use **Collect** at home to move earned rent into your wallet.

Follow the roads to the nearest **Starter Lane** landlord plot. Press its prefab prompt and stay nearby through the server's two-second theft timer. A house box grows from Normal to Big at 45 seconds and Giant at 120 seconds while it waits. Size freezes when picked up. Carrying slows you to 12 studs/s. A landlord pursues its stolen prefab after a six-second grace period while you remain within its territory; getting caught, dying or timing out returns the uncommitted prefab.

Reach your own base within 90 seconds to secure the prefab. It builds automatically on the reserved empty pad in six seconds and starts earning rent. You can also buy a known normal-size house from the **Shop** while at home. Rent depends on the design, mutation and size. Mutations are Normal, Gold, Rainbow and Void; Big and Giant sizes increase earnings.

Train beside your own treadmill using **Train**, then stop training to move. Earned speed unlocks six districts with requirements 20, 26, 34, 42, 52 and 64. Treadmill upgrades increase training rate. Base upgrades unlock up to twenty pads. Security upgrades lengthen actual base protection.

Other players can steal a finished house from an **unlocked** base. Its ownership remains with the victim until the thief reaches their own base and the server commits the transfer. The carried house pauses rent; interrupted theft returns it. Earlier rent remains with the person who earned it. Use your **House Defender** bat near a carrier to stop their escape, or activate your base lock. Join protection lasts 30 seconds; manual locks last 60–130 seconds and have a twenty-second cooldown after expiring. An active lock cannot be repeatedly extended.

Selling requires an explicit confirmation, pays half the design's configured price multiplied by size and mutation, and preserves previous rent in your base bank. Wallet overflow is banked up to the configured cap. A house cannot be sold during construction or a contested theft. A daily cash reward, discovery index, settings and live town standings support progression. Offline rent accrues at 25% for at most four hours, starting no earlier than actual ownership and construction completion.

## Content and controls

- 24 house designs, seven rarities, four mutations, three growing sizes.
- Seven exclusive bases, eighteen NPC landlord properties, six districts.
- Six base levels, ten treadmills, six functional security levels.
- Server-owned contested loot, saved house UID ownership, carry recovery and sale/purchase journals.
- Responsive house inventory, shop, discovery index, standings, daily rewards and settings.
- Keyboard: **E** interact, **R** defend, **Shift** run, **T** train, **L** lock, **V** collect.
- Touch: Roblox prompts and visible action buttons. Controller: **X** interact, **D-pad Up** houses, **B** close, **R2** defend, **L3** run, **Y** train; D-pad menu navigation.

No external model or Toolbox dependency is required. Music and effects accept your own sound asset IDs and are silent by default. Robux products, pet models, trading, conveyors and rebirth are not active systems. A commercial art/audio pass and real Roblox testing are still needed before release.

## Architecture and development

Rojo separates `src/shared`, `src/server`, and `src/client`. A single server bootstrap constructs independent modules for profiles, canonical ownership, houses/economy, growing wild prefabs, plots/models, theft, guarding, progression, players, movement validation and networking. Clients render snapshots and request actions; they do not decide currency, rarity, ownership or completion. See [architecture](docs/ARCHITECTURE.md) and [service contracts](docs/CONTRACTS.md).

On Linux x86_64 with Python 3 and curl:

```sh
python3 scripts/setup.py
python3 scripts/check.py
python3 scripts/package.py
```

The setup verifies official pinned Rojo 7.6.1 and Luau 0.699 downloads over TLS using SHA-256. `check.py` builds `build/StealAHouse.rbxlx`, compares every embedded source with current Luau files, checks exactly one server/client bootstrap, compiles every source, and runs actual-source regression suites. `package.py` verifies the complete place/source ZIP and generates its offline transfer script. Tools and ordinary build output are ignored by Git.

On Windows/macOS, install the matching official Rojo CLI and run:

```sh
rojo build default.project.json -o StealAHouse.rbxlx
```

The optional official Rojo Studio plugin supports live editing with `rojo serve default.project.json`. Opening the built place needs no plugin.

## Roblox Studio setup

1. Set **maximum players to 7** and **avatar type to R15** in the experience settings.
2. Play is possible without publishing or enabling API access. Default `Config.Game.StudioPersistence = false` displays **Studio temporary** and resets practice progress when Play stops.
3. For save testing, use a **separate published test experience**, set **both** `ProfileStore` and `OwnershipStore` to distinct test names in `ReplicatedStorage.Shared.Config`, enable **Studio Access to API Services** in that test experience, and set `StudioPersistence = true`. The two stores belong together; do not reset or rename only one of them. Live servers always use real DataStores and fail closed on unavailable profiles/ownership.
4. Run **Server & Clients** with at least two clients and follow the [Studio checklist](docs/VALIDATION.md). Check server and client Output. Gameplay, physics, replication, DataStores, native input and performance have not been executed in Roblox Studio from this Linux workspace.
5. Optional: set licensed sound IDs in `Config.Game.Audio`. No HTTP permission, API keys, private packages or Marketplace IDs are required for gameplay.

Cash/training/rent use periodic profile saves and can lose unsaved increments on a server crash. House ownership uses an independent per-UID compare-and-swap ledger and durable owner discovery; pending purchase/sale awards recover on rejoin. A completely unavailable ownership store pauses uncertain transfers instead of displaying duplicate houses. See the architecture notes for the bounded abandoned-index limitation and movement-validation scope.
